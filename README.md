# Make a Site

Make a Site is a free platform that lets users create beautiful birthday websites in minutes. With a few simple steps, people can design a personalized digital celebration page for birthdays, share memories, collect wishes from friends and family, and publish it online.

## Features

- Create custom birthday website templates
- Add personal messages, memories, and event details
- Showcase photo galleries and special moments
- Let guests leave birthday wishes in a guestbook
- Publish the site for easy sharing with family and friends
- Simple dashboard for managing multiple websites

## Tech Stack

- Next.js
- React
- Prisma
- PostgreSQL
- Cloudflare R2 for asset storage
- Authentication and user management

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Project Goal

This project helps people celebrate special birthdays by making it easy to create, customize, and share a personal website without needing design or coding skills.
